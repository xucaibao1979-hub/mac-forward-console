# 交接清单

## 1. 代码归档

- `app/` Web 页面代码
- `executor/` 中央执行服务
- `deploy/` 部署和维护脚本
- `public/` 静态资源
- `.env.example` 配置模板
- `package.json` 和 `pnpm-lock.yaml` 依赖文件

## 2. 运行环境

- Ubuntu 22.04
- Node.js 22
- pnpm
- nginx
- rsync
- openssh-client

## 3. 生产服务器关键路径

```text
/opt/weixin/mac-forward-console-ubuntu
/opt/weixin/mac-forward-console-config/.env
/opt/weixin/mac-forward-console-data
/opt/weixin/mac-forward-console-runtime
```

## 4. Mac mini 连接信息

默认设备：

```text
2106 test@192.168.2.106
2108 test@192.168.2.108
2104 admin@192.168.2.104
```

请以 Web 页面“设备管理”中的实际配置为准。

## 5. 默认脚本路径

```text
2106 发送脚本 /opt/weixin/zf/twsend/2106/cs.sh
2108 发送脚本 /opt/weixin/zf/twsend/2108/cs.sh
2104 发送脚本 /opt/weixin/zf/twsend/2104/cs.sh
```

终止和清理脚本以设备管理页面配置为准。

## 6. 群名单路径

```text
2106 测试群名单 /opt/weixin/csmac2106/list/test.txt
2108 测试群名单 /opt/weixin/csmac2108/list/test.txt
2104 产线群名单 /opt/weixin/aotmac2104/list/schoollist.txt
```

以设备管理页面配置为最终生效值。

## 7. 上线前检查

- Web 页面可以访问。
- 管理员可以登录。
- 三台 Mac mini SSH 免密登录正常。
- 设备运行状态可以刷新。
- 群名管理可以读取文件。
- 测试群发送正常。
- 停止发送脚本正常。
- 操作日志正常记录。
- 数据目录已备份。

## 8. 更新注意事项

- 更新前备份 config 和 data。
- 不要覆盖 `/opt/weixin/mac-forward-console-config/.env`。
- 不要删除 `/opt/weixin/mac-forward-console-data`。
- 更新后执行重启脚本。
- 如页面异常，先查看 web.log 和 executor.log。
