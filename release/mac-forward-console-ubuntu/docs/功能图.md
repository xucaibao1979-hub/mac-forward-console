## 2. 页面功能关系图

```mermaid
flowchart TB
    A[工作台] --> A1[查看设备状态]
    A --> A2[快速执行设备操作]
    A --> A3[查看最近任务和操作日志]

    B[发送中心] --> B1[选择转发方式]
    B1 --> B11[本地直接图文转发]
    B1 --> B12[选择文本内容发送]
    B --> B2[选择执行设备]
    B --> B3[选择产线或测试群列表]
    B --> B4[选择执行脚本]
    B --> B5[立即执行或定时执行]

    C[群名管理] --> C1[读取设备群名路径]
    C --> C2[维护产线群名]
    C --> C3[维护测试群名]
    C --> C4[保存并生成版本]

```

## 3. 核心业务闭环

```mermaid
flowchart LR
    Device[设备管理<br/>配置 Mac mini 和脚本] --> Group[群名管理<br/>维护产线 / 测试群]
    Message[发送信息管理<br/>维护文本内容] --> Send[发送中心<br/>创建发送任务]
    Group --> Send
    Device --> Send
    Send --> Task[任务记录<br/>状态 / 耗时 / 结果]
    Task --> Log[操作日志<br/>审计和排查]
    Log --> Maintain[维护处理<br/>调整设备 / 脚本 / 群名]
    Maintain --> Device
```

## 5. 发送方式功能图

```mermaid
flowchart TB
    SendTask[创建发送任务] --> Mode{转发方式}

    Mode -->|本地直接转发| Local[调用图文发送脚本]
    Local --> LocalList[读取产线或测试群列表]
    LocalList --> LocalRun[在企业微信中转发现有图文]

    Mode -->|选择发送文本| Text[选择文本内容]
    Text --> TextList[读取产线或测试群列表]
    TextList --> TextRun[逐群发送指定文本]

    SendTask --> Device{执行设备}
    Device --> Single[单台 Mac mini]
    Device --> Multi[多台 Mac mini 同时执行]

    SendTask --> Time{执行时间}
    Time --> Now[立即执行]
    Time --> Schedule[定时执行]
```
