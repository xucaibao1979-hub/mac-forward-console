# 机器人中控台归档说明

本目录是用于 Ubuntu 22.04 部署的完整交付包，包含服务代码、启动脚本、部署文档、维护文档、操作手册和常用运维脚本。

## 一、目录说明

```text
mac-forward-console-ubuntu/
├── app/                         Web 页面代码
├── executor/                    后端执行服务
├── public/                      Logo、图标等静态资源
├── deploy/
│   ├── simple/                  简单启动、停止、重启、备份、同步脚本
│   ├── systemd/                 开机自启与系统加固脚本
│   ├── ssl/                     SSL 证书配置说明
│   ├── sso/                     IT 小爱免登接入说明
│   └── ubuntu/                  Mac mini 调用脚本、清理脚本、nginx 示例
├── docs/
│   ├── 部署文档.md
│   ├── 维护文档.md
│   ├── 操作手册.md
│   ├── 架构说明.md
│   ├── 功能图.md
│   ├── 交接清单.md
│   └── 归档说明.md
├── .env.example                 配置文件模板
├── package.json
├── pnpm-lock.yaml
└── README.md
```

## 二、优先阅读顺序

1. `README.md`：先看整体说明。
2. `docs/部署文档.md`：新服务器部署时使用。
3. `docs/操作手册.md`：日常页面操作使用。
4. `docs/维护文档.md`：升级、备份、同步、排查问题时使用。
5. `docs/架构说明.md`：交接给技术人员时使用。
6. `docs/功能图.md`：产品培训、验收和功能说明时使用。
7. `docs/交接清单.md`：上线前检查使用。

## 三、部署方式

推荐部署路径：

```bash
/opt/weixin/mac-forward-console-ubuntu
```

配置文件推荐放到程序目录之外：

```bash
/opt/weixin/mac-forward-console-config/.env
```

数据目录推荐放到程序目录之外：

```bash
/opt/weixin/mac-forward-console-data
```

这样后续替换新版本代码时，不会覆盖设备配置、用户、权限、群名路径、任务记录、操作日志等数据。

## 四、常用脚本

简单启动：

```bash
bash deploy/simple/start.sh
```

停止服务：

```bash
bash deploy/simple/stop.sh
```

重启服务：

```bash
bash deploy/simple/restart.sh
```

备份服务：

```bash
bash deploy/simple/backup-console.sh
```

同步最新备份到另一台机器：

```bash
bash deploy/simple/scp-latest-backup.sh
```

同步三台 Mac mini 的群名文件：

```bash
bash deploy/simple/sync-group-files.sh
```

## 五、开机自启

如需设置开机自启，参考：

```text
deploy/systemd/README-系统加固与开机启动.txt
```

安装服务：

```bash
bash deploy/systemd/install-service.sh
```

重启 systemd 服务：

```bash
bash deploy/systemd/restart-service.sh
```

## 六、SSL 证书

如需使用 `https://bot.saybot.net` 访问，参考：

```text
deploy/ssl/README-SSL证书.txt
deploy/ubuntu/nginx-mac-forward-console.conf
```

证书路径示例：

```text
/usr/local/src/ssl/fullchain.cer
/usr/local/src/ssl/star.saybot.net.key
```

## 七、备份策略

默认本地备份保留 30 天，超过自动删除。

备份脚本：

```text
deploy/simple/backup-console.sh
```

同步脚本：

```text
deploy/simple/scp-latest-backup.sh
```

## 八、升级建议

升级时建议只替换程序目录：

```text
/opt/weixin/mac-forward-console-ubuntu
```

不要删除以下目录：

```text
/opt/weixin/mac-forward-console-config
/opt/weixin/mac-forward-console-data
/opt/weixin/mac-forward-console-runtime
```

替换完成后执行：

```bash
bash deploy/simple/restart.sh
```

或 systemd 方式：

```bash
bash deploy/systemd/restart-service.sh
```
