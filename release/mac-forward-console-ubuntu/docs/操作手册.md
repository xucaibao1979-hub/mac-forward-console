# 操作手册

## 1. 登录

访问中控台地址，例如：

```text
https://bot.saybot.net
```

输入管理员或普通用户账号密码登录。普通用户只能看到已授权功能。

## 2. 工作台

工作台用于查看整体状态：

- 设备运行状态
- 最近任务
- 操作日志
- 一键清理磁盘 All
- 一键开始发送 All
- 一键停止发送 All

最近任务和操作日志默认显示最近 7 天，支持按日期筛选和全屏查看。

## 3. 创建发送任务

进入“发送中心”，点击“新建定制任务”。

常用选项：

- 转发方式：本地直接转发或选择发送文本。
- 执行设备：选择单台或多台 Mac mini。
- 发送群列表：选择产线或测试。
- 执行脚本：选择设备管理中配置好的脚本。
- 执行时间：立即执行或定时执行。

图文发送会调用设备配置中的发送脚本。停止发送会调用终止脚本。

## 4. 群名管理

群名管理按设备和环境维护：

- 每台 Mac mini 独立维护群名。
- 支持产线和测试两个环境。
- 支持搜索、单行编辑、批量添加、批量删除。
- 支持设置一个首行群名和一个底部群名。
- 如果设置了底部群名，新增群名会插入到底部群名上方。
- 保存后会生成版本历史，可预览、恢复或删除。

操作建议：

1. 先选择设备。
2. 再选择产线或测试。
3. 点击刷新文件，确认读取的是正确路径。
4. 编辑群名。
5. 点击保存并应用修改。

## 5. 发送信息管理

进入“发送信息”，可以维护文本发送内容：

- 添加发送信息
- 编辑发送信息
- 删除发送信息

创建发送任务选择“选择发送文本”时，会使用这里维护的内容。

## 6. 设备管理

每台设备需要维护：

- 设备编号
- 设备名称
- IP 地址
- SSH 用户名
- SSH 端口
- 发送脚本
- 终止脚本
- 清理脚本
- 产线群名路径
- 测试群名路径
- VNC 用户名、端口和密码
- 执行脚本组

注意：每台设备都是独立配置，不能混用脚本和群名路径。

## 7. 任务记录

任务记录可以查看：

- 任务编号
- 设备
- 类型
- 创建时间
- 耗时
- 状态

支持搜索、日期筛选、全屏查看和删除。

## 8. 设置

设置中包含：

- 运行参数
- 用户与权限
- 操作日志
- 管理员密码
- 服务状态

普通用户只显示自己有权限访问的功能。

## 9. 用户权限

常用权限：

- 创建任务：允许创建发送任务。
- 终止任务：允许停止发送。
- 磁盘清理：允许执行清理脚本。
- 查看日志：允许查看任务和日志。
- 设备配置：允许维护设备配置。
- 群名管理：允许维护群名。
- 用户管理：允许管理用户权限。

管理员可以给用户生成免登密钥。IT 小爱使用长期密钥换取一次性登录地址，再跳转到中控台。
