# 架构说明

本文用于项目交接、部署说明和后续维护。当前系统定位为“机器人中控台”，通过 Web 页面统一管理 Mac mini 设备、群名文件、发送任务、脚本执行、操作日志和用户权限。

## 1. 系统架构图

```mermaid
flowchart LR
    U[管理员 / 普通用户] --> B[浏览器]
    B -->|HTTP / HTTPS| N[Nginx<br/>80 / 443]
    N -->|反向代理| W[Web 页面服务<br/>127.0.0.1:3000]
    W -->|API 请求| E[中央执行服务<br/>127.0.0.1:8787]

    E --> D[(持久化数据目录<br/>/opt/weixin/mac-forward-console-data)]
    E --> R[运行日志目录<br/>/opt/weixin/mac-forward-console-runtime]
    E --> C[配置文件<br/>/opt/weixin/mac-forward-console-config/.env]

    E -->|bash / ssh / scp / rsync| S[服务端脚本目录<br/>/opt/weixin]

    S -->|SSH 免密| M2106[Mac mini 2106<br/>企业微信机器人]
    S -->|SSH 免密| M2108[Mac mini 2108<br/>企业微信机器人]
    S -->|SSH 免密| M2104[Mac mini 2104<br/>企业微信机器人]

    M2106 -->|pyautogui 操作企业微信| WX1[企业微信客户端]
    M2108 -->|pyautogui 操作企业微信| WX2[企业微信客户端]
    M2104 -->|pyautogui 操作企业微信| WX3[企业微信客户端]
```

说明：

- 用户只通过浏览器操作，不需要登录服务器执行命令。
- Nginx 负责域名、SSL 和反向代理。
- Web 页面服务负责页面展示和交互。
- 中央执行服务负责登录鉴权、设备配置、任务调度、脚本调用、日志记录和数据持久化。
- Mac mini 不需要部署 Web 服务，只保留企业微信、Python 自动化环境和远程登录能力。

## 3. 发送任务流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Web as Web 页面
    participant API as 中央执行服务
    participant File as 群名文件
    participant Shell as 服务端脚本
    participant Mac as Mac mini
    participant WX as 企业微信

    User->>Web: 创建发送任务
    Web->>API: 提交设备、群列表、转发方式、脚本
    API->>API: 校验用户权限
    API->>File: 读取产线或测试群名
    API->>Shell: 调用对应发送脚本
    Shell->>Mac: scp 群名文件 / ssh 执行 Python
    Mac->>WX: 自动打开群并转发图文或发送文本
    WX-->>Mac: 执行完成
    Mac-->>Shell: 返回执行结果
    Shell-->>API: 返回成功 / 失败 / 超时
    API->>API: 写入任务记录和操作日志
    API-->>Web: 返回任务状态
    Web-->>User: 展示执行结果和耗时
```

## 4. 群名管理流程图

```mermaid
flowchart LR
    A[选择设备] --> B[选择产线 / 测试]
    B --> C[读取设备配置中的群名路径]
    C --> D[加载群名文件]
    D --> E[页面编辑群名]
    E --> F{是否保存}
    F -->|否| G[撤销或离开]
    F -->|是| H[写入原群名文件]
    H --> I[生成版本历史]
    I --> J[记录操作日志]
    J --> K[发送任务使用最新群名]
```

说明：

- 产线群名和测试群名分别绑定独立文件路径。
- 每台设备的群名文件独立维护，不能串用。
- 新增群名不会自动删除重复项，只提示重复，由管理员手动处理。
- 如果设置了底部群名，新增内容会插入到底部群名上方。

## 6. 权限模型

```mermaid
flowchart LR
    Login[用户登录] --> Auth[鉴权]
    Auth --> Admin{是否管理员}
    Admin -->|是| All[拥有全部功能]
    Admin -->|否| Perm[读取用户授权权限]

    Perm --> P1[工作台]
    Perm --> P2[创建任务]
    Perm --> P3[任务记录]
    Perm --> P4[群名管理]
    Perm --> P5[设备配置]
    Perm --> P6[磁盘清理]
    Perm --> P7[终止任务]
    Perm --> P8[用户管理]
    Perm --> P9[查看日志]
```

说明：

- 管理员拥有全部权限。
- 普通用户只能看到已授权菜单和操作按钮。
- 群名维护人员可单独授权“群名管理”权限。
- 用户权限保存在持久化数据目录中，升级代码不会丢失。

## 7. 持久化和配置模型

```mermaid
flowchart TB
    ENV[.env 配置文件<br/>/opt/weixin/mac-forward-console-config/.env]
    DATA[state.json<br/>/opt/weixin/mac-forward-console-data/state.json]
    RUNTIME[运行日志<br/>/opt/weixin/mac-forward-console-runtime]
    GROUPS[群名文件<br/>/opt/weixin/*/list/*.txt]
    CODE[程序目录<br/>/opt/weixin/mac-forward-console-ubuntu]

    ENV --> APP[服务启动]
    DATA --> APP
    GROUPS --> APP
    APP --> RUNTIME
    CODE --> APP
```

建议：

- 程序目录可以随版本替换。
- 配置目录、数据目录、运行日志目录和群名文件目录不要放在程序发布目录里。
- 这样升级版本时不会丢失设备配置、用户权限、任务记录、操作日志和群名文件。
