# 维护文档

## 1. 服务组成

机器人中控台由两部分组成：

- Web 页面：提供登录、任务、设备、群名、日志等操作界面。
- 中央执行服务：保存数据、执行本地脚本、通过 SSH 调用 Mac mini、采集设备状态。

## 2. 关键目录

```text
/opt/weixin/mac-forward-console-ubuntu       程序代码目录
/opt/weixin/mac-forward-console-config/.env  服务配置文件
/opt/weixin/mac-forward-console-data         永久数据目录
/opt/weixin/mac-forward-console-runtime      运行日志和 PID 目录
```

更新版本时，只替换程序代码目录，不要删除 data/config/runtime 目录。

## 3. 常用命令

查看服务状态：

```bash
systemctl status mac-forward-executor mac-forward-web nginx
```

重启服务：

```bash
cd /opt/weixin/mac-forward-console-ubuntu
bash deploy/systemd/restart-service.sh
```

简易方式重启：

```bash
cd /opt/weixin/mac-forward-console-ubuntu
bash deploy/simple/restart.sh
```

查看日志：

```bash
tail -f /opt/weixin/mac-forward-console-runtime/logs/executor.log
tail -f /opt/weixin/mac-forward-console-runtime/logs/web.log
```

## 4. 数据备份

至少备份以下目录：

```bash
tar -czf /opt/weixin/mac-forward-console-backup-$(date +%F).tar.gz \
  /opt/weixin/mac-forward-console-config \
  /opt/weixin/mac-forward-console-data
```

建议在每次更新版本前备份一次。

归档内也提供了自动备份脚本：

```bash
cd /opt/weixin/mac-forward-console-ubuntu
chmod +x deploy/simple/backup-console.sh
bash deploy/simple/backup-console.sh
```

默认备份到：

```text
/opt/weixin/mac-forward-console-backups
```

默认保留最近 30 天备份。可以通过变量调整：

```bash
KEEP_DAYS=30 BACKUP_DIR=/data/weixin-backups bash deploy/simple/backup-console.sh
```

如果要同步一份到另一台机器：

```bash
REMOTE_BACKUP_HOST=root@192.168.1.88 bash deploy/simple/backup-console.sh
```

如果希望先本地备份，再单独用 scp 同步最新备份包：

```bash
cd /opt/weixin/mac-forward-console-ubuntu
chmod +x deploy/simple/scp-latest-backup.sh
bash deploy/simple/scp-latest-backup.sh
```

scp 同步脚本默认目标：

```text
root@192.168.1.88:/opt/weixin/mac-forward-console-backups
```

远端默认保留最近 30 天备份，超过自动删除。可通过变量调整：

```bash
BACKUP_USER=bk BACKUP_HOST=192.168.0.59 BACKUP_DIR=/backup/server-backup/ITxiaoai SSH_KEY=/root/.ssh/id_rsa KEEP_DAYS=180 bash deploy/simple/scp-latest-backup.sh
```

每天凌晨 2 点自动备份：

```bash
0 2 * * * cd /opt/weixin/mac-forward-console-ubuntu && bash deploy/simple/backup-console.sh >> /opt/weixin/mac-forward-console-backups/cron.log 2>&1
```

## 5. 版本更新

```bash
cd /opt/weixin
cp -a mac-forward-console-ubuntu mac-forward-console-ubuntu.bak.$(date +%F-%H%M)
tar -xzf mac-forward-console-ubuntu.tar.gz
cd mac-forward-console-ubuntu
pnpm install --frozen-lockfile
bash deploy/systemd/restart-service.sh
```

如果只是简单运行，没有 systemd：

```bash
bash deploy/simple/restart.sh
```

## 6. 群名单同步到 192.168.1.88

如果需要把 192.168.1.77 的群名单同步到 192.168.1.88，可使用：

```bash
rsync -az /opt/weixin/csmac2106/list/schoollist.txt root@192.168.1.88:/opt/weixin/csmac2106/list/schoollist.txt
rsync -az /opt/weixin/csmac2108/list/schoollist.txt root@192.168.1.88:/opt/weixin/csmac2108/list/schoollist.txt
rsync -az /opt/weixin/aotmac2104/list/schoollist.txt root@192.168.1.88:/opt/weixin/aotmac2104/list/schoollist.txt
```

也可以使用归档内脚本：

```bash
REMOTE_HOST=root@192.168.1.88 bash deploy/simple/sync-group-files.sh
```

## 7. 常见问题

### 页面 502

检查 Web 是否启动：

```bash
ss -lntp | grep -E ':3000|:8787'
tail -n 100 /opt/weixin/mac-forward-console-runtime/logs/web.log
```

### 页面提示接口不存在

检查执行服务版本是否正确：

```bash
curl http://127.0.0.1:8787/api/health
```

### 设备连接失败

检查服务机器到 Mac mini 的免密 SSH：

```bash
ssh test@192.168.2.106
ssh test@192.168.2.108
ssh admin@192.168.2.104
```

### 发送任务显示失败但实际发送成功

检查 `.env` 中发送超时配置：

```env
SEND_TIMEOUT_SECONDS=14400
```

修改后重启服务。

### 磁盘清理无变化

确认清理脚本实际清理的是企业微信缓存目录，且 Mac mini 上企业微信缓存确实存在。可以在 Mac mini 上查看：

```bash
du -sh "$HOME/Library/Containers/com.tencent.WeWorkMac/Data/Documents/cefcache"
du -sh "$HOME/Library/Containers/com.tencent.WeWorkMac/Data/Library/Caches"
```

## 8. 安全维护

- 管理员密码应定期修改。
- SSH 建议禁用密码登录，仅保留密钥登录。
- `.env` 权限建议设置为 `600`。
- 数据备份文件不要放在 Web 可访问目录。
- 如使用公网域名，必须启用 HTTPS。
