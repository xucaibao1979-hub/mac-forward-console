# 部署文档

## 1. 服务器要求

- 系统：Ubuntu 22.04
- 用户：建议使用 root 或具备 sudo 权限的运维用户
- 网络：服务机器可以 SSH 免密登录三台 Mac mini
- 端口：Web 默认 `3000`，执行服务默认 `8787`，如使用 Nginx 则对外开放 `80/443`

## 2. 安装基础依赖

```bash
apt update
apt install -y curl rsync openssh-client nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
npm install -g pnpm
```

## 3. 上传代码

推荐部署目录：

```bash
mkdir -p /opt/weixin
cd /opt/weixin
tar -xzf mac-forward-console-ubuntu.tar.gz
cd /opt/weixin/mac-forward-console-ubuntu
```

## 4. 安装项目依赖

```bash
pnpm install --frozen-lockfile
```

## 5. 初始化配置

首次启动会自动创建：

```text
/opt/weixin/mac-forward-console-config/.env
/opt/weixin/mac-forward-console-data
/opt/weixin/mac-forward-console-runtime
```

也可以手动创建：

```bash
mkdir -p /opt/weixin/mac-forward-console-config
cp .env.example /opt/weixin/mac-forward-console-config/.env
```

常用配置：

```env
WEB_HOST=127.0.0.1
WEB_PORT=3000
PUBLIC_HOST=bot.saybot.net
EXECUTOR_PORT=8787
CONSOLE_ORIGIN=https://bot.saybot.net
DATA_DIR=/opt/weixin/mac-forward-console-data
RUNTIME_DIR=/opt/weixin/mac-forward-console-runtime
CLEAN_TIMEOUT_SECONDS=900
SEND_TIMEOUT_SECONDS=14400
ADMIN_INITIAL_PASSWORD=123456
CONFIG_ENCRYPTION_KEY=change-this-to-a-long-random-secret
```

说明：

- `DATA_DIR` 是永久数据目录，更新代码时不能删除。
- `SEND_TIMEOUT_SECONDS=14400` 表示发送任务最长允许执行 4 小时。
- `CONFIG_ENCRYPTION_KEY` 部署后不要随意修改，否则已加密的 VNC 密码等凭据可能无法解密。

## 6. 简易启动

```bash
chmod +x deploy/simple/*.sh
bash deploy/simple/start.sh
```

停止：

```bash
bash deploy/simple/stop.sh
```

重启：

```bash
bash deploy/simple/restart.sh
```

## 7. 开机自启动

```bash
chmod +x deploy/systemd/*.sh
bash deploy/systemd/install-service.sh
systemctl enable mac-forward-executor mac-forward-web
systemctl restart mac-forward-executor mac-forward-web
```

检查：

```bash
systemctl status mac-forward-executor mac-forward-web nginx
```

## 8. Nginx 反向代理

如果使用域名 `bot.saybot.net` 和 HTTPS，请参考：

```text
deploy/ssl/README-SSL证书.txt
```

核心代理目标：

```text
http://127.0.0.1:3000
```

同时需要保证 `/api` 可以代理到 Web，由 Web 再转发到执行服务。

## 9. Mac mini 免密登录

在服务机器上测试：

```bash
ssh test@192.168.2.106
ssh test@192.168.2.108
ssh admin@192.168.2.104
```

如果不能免密，配置 SSH key：

```bash
ssh-copy-id test@192.168.2.106
ssh-copy-id test@192.168.2.108
ssh-copy-id admin@192.168.2.104
```

## 10. 首次登录

默认管理员：

```text
账号：admin
密码：123456
```

首次登录后请进入右上角设置，修改管理员密码。
